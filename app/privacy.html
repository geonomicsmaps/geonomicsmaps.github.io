Privacy policy · Ares Medya Yayin

Last updated: 11 November 2026.

Ares Medya Yayin is a private tool used only by its owner to manage the owner's own YouTube channels. It has no other users.

What Google data it accesses

With the owner's permission (Google OAuth), it uses the YouTube Data API and YouTube Analytics API to upload and update the owner's videos, thumbnails and captions, post comments from the owner's channel, and read statistics (views, watch time, retention, click-through rate) for the owner's channels.

How it is used and stored

Data is used only to publish the owner's videos and to measure their performance. Access tokens are stored only on the owner's own computer (macOS Keychain). Statistics are stored in the owner's private files. No data is sold, shared with third parties, or used for advertising.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
